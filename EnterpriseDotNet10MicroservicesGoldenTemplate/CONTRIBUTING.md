# Contributing

1. Create or reference the work item.
2. Create/update the Spec Kit artifacts.
3. Create a feature/bugfix branch.
4. Implement only the approved scope.
5. Add or update tests.
6. Run `dotnet build Enterprise.sln` and `dotnet test Enterprise.sln` locally.
7. Open a pull request using the repository template.
8. Address CODEOWNERS and CI feedback.
9. Merge only after all required gates pass.

Do not commit secrets or local environment files.
